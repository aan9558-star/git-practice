## Article

[AI is changing this job so fast the interview process can’t keep up](https://www.cnn.com/2026/05/28/tech/ai-software-engineering-job-interview) by Lisa Eadicicco, published by CNN on May 28, 2026.

## Why I Found It Interesting

I found this article interesting because AI is changing what software engineers do, and how companies interview them. It explains how AI can not only help with writing code, but also now with documentation, troubleshooting, and learning programming concepts. Traditional coding interviews may no longer reflect what software engineering work actually looks like. Additionally, the article discussed how software engineers may spend more time deciding **what should be built** and less time writing the actual lines of code. Understanding how technology works, making good decisions, and knowing how to use AI tools effectively is becoming just as important as knowing how to write code.
