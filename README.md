## Article

[AI is changing this job so fast the interview process can’t keep up](https://www.cnn.com/2026/05/28/tech/ai-software-engineering-job-interview) by Lisa Eadicicco, published by CNN on May 28, 2026.

## Why I Found It Interesting

I found this article interesting because AI is changing what software engineers do and how companies evaluate people who want to become software engineers. The article explains that AI can now help with writing code, documentation, troubleshooting, and learning programming concepts. Because of this, traditional coding interviews may not always reflect what software engineering work actually looks like.

Another part I found interesting is the idea that software engineers may spend more time deciding **what should be built** and less time writing every line of code themselves. I think this raises an important question about what skills will matter in software development in the future. Understanding how technology works, solving problems, making good decisions, and knowing how to use AI tools effectively is becoming just as important as knowing how to write code from scratch.
